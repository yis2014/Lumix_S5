# 主核系统调用桩表（0x868E5948 – 0x868E59C8）

postboot 模块（postboot1/3/5）通过这张表调用 program 内的底层服务。
表项是 4 字节的 `b.w` 跳转桩（位置无关），因此**任何注入到 RAM 的 payload 都可以直接调用这些地址**。

## 用法示例（payload 内）

```asm
ldr  r0, =0x868E59A0      ; 日志桩
movw r1, #0xC040          ; 消息 ID
blx  r0
```

## 已知关联

- `\restore.bin` 命令处理（postboot3，0x87734606）：命令 id `0x390`，依次调用
  0x868E5948 → 0x868E5950 → 0x868E594C
- 日志消息 ID 形如 `0xC040`，字符串由主核按 ID 查表输出，**无法从字符串反查代码**
