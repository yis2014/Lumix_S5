# payloads

C 源码用 ARM GCC 编译成 Thumb 二进制，加载地址固定 0x86370000。

## 构建

```powershell
# 工具链：tools/armgcc/xpack-arm-none-eabi-gcc-15.2.1-1.1
# 注意 gcc 需要可写临时目录（本仓库 .tmp）
```

见 `build.ps1`（若 `pwsh` 不可用，可用同样的参数手动调用 gcc/objcopy）。

## 现有程序

| 文件 | 用途 |
|---|---|
| `test_marker.c` | 最小验证：写 0xCAFEBABE 到 0x8F300010 |
| `sd_probe.c` | 调用 SDD_Read 读扇区 0，把返回值/数据记到 0x8F300020 |

## 调用约定

程序以函数形式被调用（lr 指向返回地址），返回时执行 `bx lr` 即可。

## 绝对地址（编译期常量）

| 地址 | 用途 |
|---|---|
| 0x8F300000 | 标记区（测试） |
| 0x8F300020 | sd_probe 结果 |
| 0x8F303000 | 扇区偏移暂存 |
| 0x8F304000 | 读缓冲（4 KiB） |
| 0x86370000 | 程序加载地址（最大 256 KiB） |

⚠️ 传入固件函数的地址要用**虚拟形式**（物理 − 0x80000000）。
