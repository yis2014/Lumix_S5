# LumixTool

给 Panasonic LUMIX 相机用的本地工具箱：通过服务模式的 USB 接口，把相机里的提示音（比如半按快门的对焦音）换成你自己的声音。

> ⚠️ **预发布阶段**：暂时只在**松下 S5 + v2.9 固件**上进行过验证，写入流程还在实机验证中。请先用短音频、单个音效试用。

- 只改相机 **RAM**，不写 flash：电源键关机再开机（热重启）后仍然有效，**拔电池或恢复出厂就会还原**。
- 音效写在相机 RAM 的一块暂存区（`0x8F000000` 起）里，写入前会检查，不会覆盖其它已写入的音效。
- 完全本地运行，不联网。

![音效替换：列出相机的 28 项音效](docs/images/sounds-list.png)

## 功能

| 工具 | 说明 |
|---|---|
| **音效替换** | 列出相机音效表的全部 28 项，可以单项或批量写入自定义音频，逐项或全部恢复原厂。支持 wav / mp3 / m4a / flac / ogg / opus，自动转成 44.1 kHz 单声道，最长 3 秒。 |
| **内存诊断** | 只读扫描相机 RAM 暂存区，用分布图显示哪里空闲、哪里有数据、每个音效存在哪里，可导出 JSON。 |
| **连接指南** | 一键安装 WinUSB 驱动、检测驱动状态、引导进入服务模式。 |

目前只确认了 **#1 = 半按快门对焦提示音**，其它 27 项对应哪个动作还不清楚，可以用批量写入按二分法找，方法见 [docs/SOUND_TABLE.md](docs/SOUND_TABLE.md)。找到后可以在应用里给音效改名，名称保存在本机。

## 系统要求

- Windows 10 / 11（64 位）。macOS / Linux 只能用模拟模式开发界面，不能连相机。
- Panasonic LUMIX 相机（暂时只在松下 S5 + v2.9 固件上验证过），以及一根能传数据的 USB 线。
- 相机内存地址与固件版本有关。连接后如果检测到**未验证过的固件版本**，应用只开放查看和内存扫描，会禁用写入和恢复，避免写错位置。
- 不需要安装 Python，安装包里已经自带。

## 下载与安装

1. 到 [Releases](https://github.com/USER-HFC/Lumix_Tool/releases) 下载最新的 `LumixTool-<版本>-win-x64.zip`。
2. 右键 →「全部解压」，**把解压出来的文件夹放到桌面或「文档」**，然后双击里面的 `LumixTool.exe`。不要在压缩包里直接运行。
3. `LumixTool.exe` 没有代码签名，第一次运行时 Windows SmartScreen 会拦截，点「更多信息 → 仍要运行」。

## 使用步骤

1. **进入服务模式**：相机关机，按住 `PLAY` + `AF-ON` 不放，再开机，然后用 USB 连接电脑。设备管理器里出现 `04DA:2370` 就说明进入成功（这是在 S5 上观察到的服务模式 USB 标识，应用目前也只识别这个标识）。关机后正常开机即可退出服务模式。
2. **安装驱动**（只需一次）：打开「连接指南」，点「一键安装驱动」，在弹出的 Windows 管理员确认里点「是」。安装失败的话，展开「高级」改用 Zadig 手动安装，见 [docs/DRIVER_SETUP.md](docs/DRIVER_SETUP.md)。
3. **检查连接**：右上角显示「已连接」和机身版本即可。
4. **（建议）扫描内存**：打开「内存诊断」，点「扫描内存」。扫描只读，大约需要几十秒到两分钟。不扫也可以，第一次写入时会自动扫描。
5. **替换音效**：在「音效替换」里勾选要换的音效（建议第一次只选 #1），拖入音频，点「写入」。
6. **热重启试听**：写入完成后，用**电源键**关机再开机（**不要拔电池**），然后触发对应动作试听，比如半按快门听对焦音。
7. **恢复原厂**：在音效列表里点「恢复」或「全部恢复」，然后热重启；或者直接拔电池。

## 注意事项

- **写入很慢**：每个采样点约 2 ms，1 秒音频大约要 1.5 分钟。服务模式空闲 4–7 分钟会自动关机，写长音频时请隔一会儿点一下相机触摸屏，保持唤醒。写入期间不要拔 USB 或关机。
- **原厂备份**：每次连接相机时，应用会读取音效表，把还没被改过的原厂表项按机身版本保存在本机，恢复时用的就是这份备份。如果某项在应用第一次连接之前就已经被改过，这一项没法单独恢复，只能拔电池还原。
- **空间有限**：可写入的空闲内存大小因机器而异，以「内存诊断」的扫描结果为准。空间不够时，应用会在写入前提示，不会写到一半。
- **一键安装驱动**会在本机安装一个自签名证书，用于签名驱动包，只绑定 `04DA:2370` 这一个设备。可以在「高级」里卸载驱动并移除证书。

## 常见问题

**双击 `LumixTool.exe` 后几秒就退出，没有窗口**

多半是程序所在文件夹的权限问题：LumixTool 的界面进程（Chromium）以受限身份运行，只能读取 `Users` 组可读的文件。如果文件夹权限只给了你自己的账户（某些数据盘或被安全软件管理的目录会这样），界面进程就启动不了。用管理员运行时，会弹出「LumixTool 无法启动」的提示。解决办法任选其一：

- 把整个文件夹移到桌面或「文档」再运行。
- 给所在目录加上 Users 组读取权限，子目录会自动继承：

  ```bat
  icacls "F:\你的目录" /grant *S-1-5-32-545:(OI)(CI)RX
  ```

**驱动显示正常，但一直「未连接」**

拔掉 USB 线重新插上，再点「检查连接」。仍然不行的话，「连接指南」里会显示具体原因，比如没有进入服务模式，或者设备被其它程序占用。

**音效页提示「固件未经验证，已禁用写入和恢复」**

应用用到的音效表、暂存区等地址都只在松下 S5 + v2.9 固件上确认过。在其它固件版本上，这些地址可能存放着别的数据，所以写入前会检查机身版本和音效表的结构，不符合就拒绝写入，相机不会被修改。这时仍可以用「内存诊断」扫描，欢迎把机身版本和导出的 JSON 反馈给我们，用来适配新固件。

**写入时提示「目标区域已被占用」**

说明计划写入的位置已经存放着另一个音效，校验拦下了这次写入，相机没有被修改。到「内存诊断」重新扫描一次再写：之前的扫描结果可能已经过时，比如在别的电脑上写过音效。

**写入成功，但听不到变化**

确认用的是电源键热重启，而不是拔电池；并确认触发的动作确实对应这个音效编号。目前只有 #1（半按快门对焦音）是确认过的。

## 仓库结构

| 目录 | 内容 |
|---|---|
| [`app/`](app/) | LumixTool 桌面应用（Electron + React + Ant Design，后端是 Python）。构建、开发、模拟模式和如何新增工具，见 [app/README.md](app/README.md)。 |
| [`docs/`](docs/) | 音效表结构与替换原理（[SOUND_TABLE.md](docs/SOUND_TABLE.md)）、驱动安装指南（[DRIVER_SETUP.md](docs/DRIVER_SETUP.md)）。 |
| `notes/`、`HANDOFF*.md` | DC-S5 固件研究的进展记录与交接文档。 |
| `tools/`、`js/` | 固件研究用的脚本：容器解析、固件构建、OSD 绘制、反汇编、squashfs 提取等。**属于实验性工具，其中涉及刷写固件的操作有让相机变砖的风险，不是 LumixTool 的一部分。** |

## 开发

```sh
cd app
npm ci
npm start          # 构建界面并启动
npm run dev        # 开发模式，支持热更新
npm test           # JS 测试；Python 测试：python3 -m unittest discover -s python/tests
npm run dist:win   # 打包 Windows 免安装 zip（会下载 python.org 官方嵌入版 Python）
```

没有相机时，可以用模拟模式走完全部流程：

```sh
LUMIXTOOL_MOCK=1 npm start
```
